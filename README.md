# FiLM-CAM: Keyed Feature Modulation for Conditional-Access Watermarking

Project page for the NeurIPS 2026 paper by Yash Kulthe, Shruti Agarwal, Vishal Asnani, Andrew Gilbert and John Collomosse.

Live page: https://yash-research.github.io/filmcam/

Static site (HTML/CSS/JS, no build step), served with GitHub Pages from the `main` branch.

The architecture figure (`images/method.webp`) is rendered from the paper's TikZ source in `figures/method/`. The build steps are at the top of `figures/method/method.tex`.
